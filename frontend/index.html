QUICK GUIDE

How to use Veyra

Speak naturally. Veyra understands your project command, asks for confirmation when required, and then executes the action.

01

Start speaking

Click Start Recording and speak your project command clearly.

02

Give a command

Tell Veyra what you want to do, just like you would tell a project team member.

03

Review the command

Veyra identifies the intent and important project details before carrying out the action.

04

Confirm the action

When Veyra asks for confirmation, respond with a clear confirmation phrase such as "Yes, confirm it" or "Yes, create it."

05

Get the result

After confirmation, Veyra executes the action and gives you the result through the interface and voice.

EXAMPLE COMMANDS
🎙

Create a snag for the master bathroom ceiling.

🎙

Search for snags in the master bedroom.

🎙

Update the bathroom ceiling snag.

🎙

Delete the snag in the master bedroom.

IMPORTANT

How confirmation works

For actions that require confirmation, Veyra will first ask you to confirm the command before executing it.

GOOD

"Yes, confirm it."

GOOD

"Yes, create it."

GOOD

"Yes, delete it."

GOOD

"Yes, go ahead."

Use a clear confirmation phrase so Veyra can understand that you want to proceed with the requested action.
